5 · 客户端

取参数并渲染

# 你的电脑上
scp root@你的服务器IP:/etc/sing-box/client.env ./client.env
多台设备用 device.sh，不要用本页的方式。本页的 client.env 里只有一台设备的凭据（20-secrets.sh 写的 main），多台共用同一个 uuid 就没法单独吊销。服务端跑 sudo bash device.sh add laptop 会直接生成那台的配置，你只管 scp 过去。见 第 3 页。

一次生成三端

bash docs/deploy/scripts/50-render-client.sh ./client.env --all   # 默认输出到 ./data
产出（在 data/）入站预设覆盖
sing-box-client-desktop.jsontun + mixed:2080无（沿用 client.env）
sing-box-client-android.jsontunCLIENT_MIXED=0、auto_detect_interface=true
sing-box-client-ios.jsontun同上

多端模式只覆盖这两项「平台相关」的值，其余（节点、DNS、AI 出口、规则）都来自 client.env，所以三份配置的规则完全一致。

桌面报 not valid in its context（多网卡 / 虚拟网卡的 Windows 常见）：在前面加一个变量即可，只影响桌面那份，Android 仍保持 true：
AUTO_DETECT_INTERFACE=false bash docs/deploy/scripts/50-render-client.sh ./client.env --all

只生成某一份 / 完全自定义

# 只生成安卓
bash docs/deploy/scripts/50-render-client.sh ./client.env android

# 单份模式：完全按 client.env 与命令行变量
OUT=./me.json bash docs/deploy/scripts/50-render-client.sh ./client.env

# 换输出目录
OUTDIR=/tmp/x bash docs/deploy/scripts/50-render-client.sh ./client.env --all

产物一律落在 OUTDIR（默认 ./data，已在 .gitignore 里），不会往脚本目录写。改完 client.env 后重跑即可覆盖同名文件。
