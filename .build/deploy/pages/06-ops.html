6 · 验收与备份

验收（客户端机器）

bash docs/deploy/scripts/60-verify-client.sh ./client.env

退出码：0 全过 / 1 有失败项 / 2 本地代理没起来（后面的检查已跳过）。
用 GUI.for.SingBox 时端口不同，要显式指定：PROXY=socks5h://127.0.0.1:GUI端口 bash ...

用 device.sh 管设备时：不传 client.env

走 第 3 页的设备流程时，客户端拿到的只有服务器发过去的那份 JSON。client.env 不要发过去：里面是 main 的凭据加密钥包，与“一台设备一份凭据”相背。 验收脚本真正读的只有 SERVER_IP 与 VLESS_PORT，直接给变量就行：

SERVER_IP=你的服务器IP VLESS_PORT=443 bash docs/deploy/scripts/60-verify-client.sh

# 用 GUI.for.SingBox 且端口不同时，两个变量一起给
SERVER_IP=你的服务器IP PROXY=socks5h://127.0.0.1:20122 bash docs/deploy/scripts/60-verify-client.sh

# 只验 Hysteria2 出站：脚本自己派生配置、起临时实例、跑完清理（需要本机有 sing-box）
HY2_ONLY=1 CONFIG=./client.json SERVER_IP=你的服务器IP VLESS_PORT=443 \
  bash docs/deploy/scripts/60-verify-client.sh

# 没有 sing-box CLI：只生成一份只走 hy2 的配置，导入图形客户端后再验收
HY2_ONLY=emit CONFIG=./client.json HY2_OUT=./hy2-only.json \
  bash docs/deploy/scripts/60-verify-client.sh
# 导入后：PROXY=socks5h://127.0.0.1:<客户端端口> SERVER_IP=你的服务器IP \
#   bash docs/deploy/scripts/60-verify-client.sh

没 env 文件时脚本会打一行提示后继续（VLESS_PORT 默认 443）；SERVER_IP 也不给才会报错退出。SERVER_IP 不是凭据，全设备通用，回服务器看一眼就知道：

grep SERVER_IP /etc/sing-box/client.env     # 只是取 IP，不是拷走凭据
sudo bash device.sh list                   # 确认这台在名单里
手机那份配置跑不了这个脚本。-android.json / -ios.json 只有 TUN，没有本地 2080 端口，第一项就 exit 2。手机只能在 App 里直接开浏览器自查（国内站点、Google、ChatGPT 各开一个）；要用回环脚本就把桌面那份导进来测。

备份（服务器）

cd /root/deploy
bash 70-backup.sh backup     # 备份到 /root/backups/
bash 70-backup.sh list
bash 70-backup.sh restore /root/backups/sing-box-日期.tgz

备份含私钥，等同机器凭据，别放网盘或仓库。/etc/sing-box 整个目录都会进包，所以 devices.list 与 clients/*.json 也在里面——一份备份等于全部设备的凭据，泄露就得挨个 device.sh rotate。
