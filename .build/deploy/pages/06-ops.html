6 · 验收与备份

验收（客户端机器）

bash docs/deploy/scripts/60-verify-client.sh ./client.env

退出码：0 全过 / 1 有失败项 / 2 本地代理没起来（后面的检查已跳过）。
用 GUI.for.SingBox 时端口不同，要显式指定：PROXY=socks5h://127.0.0.1:GUI端口 bash ...

备份（服务器）

cd /root/deploy
bash 70-backup.sh backup     # 备份到 /root/backups/
bash 70-backup.sh list
bash 70-backup.sh restore /root/backups/sing-box-日期.tgz

备份含私钥，等同机器凭据，别放网盘或仓库。

日常三条

vnstat -m                              # 本月流量（套餐 1TB/月，超了限速 1Mbps）
journalctl -u sing-box -n 50 --no-pager
bash 40-check-server.sh

升级 / 回滚

sudo SING_BOX_VERSION=1.15.0 bash 10-install-singbox.sh
bash 30-render-server.sh && bash 40-check-server.sh
# 回滚把版本号换回去，重跑同样两条
