4 · 可选：Hysteria2 第二入口

不做也可以，REALITY 单入口已经能用。需要你有一个域名，DNS 托管在 Cloudflare。

准备

  1. 加一条 A 记录指向你的服务器 IP，关闭 Cloudflare 代理（灰云）
  2. 创建 API Token，权限选「编辑区域 DNS」

执行

cd /root/deploy
bash 35-tls-hy2.sh        # 输入域名 / 邮箱 / Token，自动签发并续期
bash 30-render-server.sh  # 服务端开始监听 UDP
bash 40-check-server.sh

# 可选：让客户端的端口跳跃真正可用
bash 90-port-hop.sh

完成后要回到客户端重新渲染一次配置（它会读到 ENABLE_HY2=1）。
