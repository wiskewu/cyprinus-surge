部署步骤

一台 KVM VPS + sing-box，5 步跑通。除第 4 步外，命令都在服务器上执行。

懒人路径：不想逐步执行？一键脚本 deploy.sh 会扫描每一步的状态并让你选「复用 / 覆盖 / 跳过」，也支持一键卸载重装。
#做什么命令产物
1系统初始化bash 00-bootstrap.sh加固好的系统
2装 sing-box + 生成密钥bash 10-install-singbox.sh
bash 20-secrets.sh		deploy.env / client.env
3服务端配置 + 自检bash 30-render-server.sh
bash 40-check-server.sh		可连的节点
4客户端配置（在客户端机器）bash 50-render-client.shsing-box-client.json
5验收 + 备份bash 60-verify-client.sh
bash 70-backup.sh		验收记录

开始前确认

  • KVM 虚拟化：systemd-detect-virt 输出 kvm（LXC / OpenVZ 开不了 TUN）
  • 系统：Debian 12 / 13 或 Ubuntu 22.04 / 24.04
  • SSH 端口：默认 22；不是 22 的话，第 1 步要带 SSH_PORT=你的端口

把脚本传上去

scp -r docs/deploy/scripts root@你的服务器IP:/root/deploy

遇到问题

症状、日志含义、字段说明都在 排查手册，不占用主流程。
