2 · 安装与密钥

装好固定版本的 sing-box，生成本节点的参数与设备名单。执行者是有服务器 root 权限的人；做完后 /etc/sing-box 下应出现三个文件。

目标

本步只做两件事：把 sing-box 二进制与 systemd 单元装到位；生成服务端参数、客户端渲染参数与设备名单。配置渲染与服务启动留给第 3 页。

准备工作

  • 已完成第 1 页：密码登录已关，公钥能登录
  • 服务器能访问 github.com 下载 sing-box；不能访问就先把二进制传到服务器，见离线安装
  • 两条命令都需要 root
  • 准备好伪装站点域名与入口域名的取舍，取值见参数说明

实施步骤

安装二进制并生成密钥

cd /root
sudo bash bin/deploy/one/install-singbox.sh
sudo bash bin/deploy/one/secrets.sh

secrets.sh 逐项提问，回车取方括号里的默认值：

提问默认怎么填
伪装站点 REALITY_DESTwww.apple.com必须支持 TLS 1.3 与 HTTP/2。它同时是 REALITY 的回源目标，选错会让客户端握手失败
入口域名 DOMAIN留空只有要用 Hysteria2 才填。留空时客户端连公网 IP，证书流程整段跳过
启用 Hysteria2？Y仅在填了域名时出现，选 n 就只开 REALITY 单入口
第一台设备的名字main写进 devices.list，只允许字母、数字与 . _ -

换版本与离线安装

sudo SING_BOX_VERSION=1.15.0 bash bin/deploy/one/install-singbox.sh
sudo SING_BOX_PKG=/root/sing-box.tar.gz bash bin/deploy/one/install-singbox.sh
重装只换二进制，不动已加固的单元。脚本发现单元以 sing-box 用户运行时原样保留，/var/lib/sing-box 与 /etc/sing-box 的属主按单元的实际运行用户重新归位。要退回 root 全权限运行用 bin/harden/harden.sh --uninstall。
单元与运行目录属主必须一致。若单元是 User=root 而 /var/lib/sing-box 仍属 sing-box，root 的能力集里没有 CAP_DAC_OVERRIDE，750 目录的 o 位没有 x，重启会报 chdir /var/lib/sing-box: permission denied。现在 install、system、server 三步都按单元的实际用户递归归位，运行时留下的 cache.db 也在内。

重跑与换密钥

重跑保留三样东西：devices.list 里的设备凭据、REALITY 密钥对与 short_id、Hysteria2 的混淆密码。三者都嵌在已导出的客户端配置里，换了就让所有客户端当场失效。

# 重跑：只补缺的字段，客户端配置继续有效
sudo bash bin/deploy/one/secrets.sh --overwrite
sudo bash deploy.sh --only secrets --overwrite --yes

# 换新：连 REALITY 密钥对、short_id 与 HY2 混淆密码一起换掉
sudo bash bin/deploy/one/secrets.sh --rotate-secrets
sudo bash deploy.sh --only secrets --rotate-secrets --yes
sudo bash bin/deploy/device.sh export 每台设备名      # 逐台重新导出并分发
动作走参数，取值走环境变量。--overwrite 与 --rotate-secrets 是动作，写在命令行；端口、域名、Token 这些取值用环境变量或交互输入。交互模式下 secrets 每次都会问密钥是否沿用，回答 n 后还要再确认一次，两次都答对才换；回车或误敲都按沿用处理。

回退与卸载

场景动作
重装或换版本SING_BOX_VERSION=… bash bin/deploy/one/install-singbox.sh，随后补跑第 3 页的加固步骤
密钥误换新，客户端大面积失效重新对每台设备执行 device.sh export 并分发；无法恢复旧密钥
整体清除bash bin/deploy/deploy.sh --uninstall --purge --yes，删除二进制、单元、/etc/sing-box 与证书

命令手册

sudo bash bin/deploy/one/install-singbox.sh          # 装内置版本的二进制与单元
sudo bash bin/deploy/one/secrets.sh                  # 生成 deploy.env / client.env / devices.list
sudo bash bin/deploy/one/secrets.sh --overwrite      # 重跑，补齐缺失字段
sudo bash bin/deploy/one/secrets.sh --rotate-secrets # 换新客户端可见密钥
ls -l /etc/sing-box                                  # 核对产物
sing-box version                                     # 核对版本

参数说明

项默认说明
SING_BOX_VERSION脚本内置版本指定安装版本，随发布更新
SING_BOX_PKG空本地压缩包路径，用于离线安装
REALITY_DESTwww.apple.com伪装站点，需支持 TLS 1.3 与 HTTP/2
DOMAIN空Hysteria2 入口域名，留空则跳过证书
ENABLE_HY20是否启用第二入口
--overwrite无重跑时补齐缺失字段，保留已有凭据
--rotate-secrets无换新 REALITY 密钥对、short_id 与混淆密码

常见错误与排查

现象原因处理
下载失败或长时间无响应服务器访问不了 github.com本机下载后传上去，用 SING_BOX_PKG 离线安装
装完提示版本不符SING_BOX_VERSION 指向了不存在的发布去掉该变量用脚本内置版本，或改成有效版本号
重装后服务起不来，报 chdir … permission denied单元与运行目录属主不一致按SSH 加固手册的方式重新加固，或 bin/deploy/check/selfcheck.sh --fix-dac
换新密钥后客户端全部连不上客户端仍用旧 public_key 与 short_id逐台 device.sh export 重新分发；服务端日志同时出现 processed invalid connection
devices.list 被清空误删或误用 --purge用备份恢复；没有备份时只能逐台 add 重建凭据并重新分发
