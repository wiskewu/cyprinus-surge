7 · 用量显示与告警

把服务器用量与探针状态反映到客户端，并在异常时收到通知。本页同时说明为什么不引入标准订阅服务。

目标

做完后，客户端的节点名上直接显示当月用量，异常时名称后追加一个符号；服务器侧在阈值命中时向指定通道推送。目标是不新增常驻服务、不新增对外端口。

实施步骤

用节点名承载用量

客户端里能看到的名称就是出站 tag，所以把用量直接写进 tag，不引入订阅服务：

vps · 3.6G/1T         正常
vps · 3.6G/1T ⚠       最近一次探针发现服务、端口、AI 出口或丢包异常
项来源说明
用量vnstat --json m当月收发合计，配额取 MONTHLY_QUOTA，默认 1T
异常标记probe.log 最后一行，且不早于 PROBE_MAX_AGE_MIN 分钟出现 down 或 AI 出口 fail 时追加一个符号，只用单个字符避免名称过长
刷新时机重新导出设备配置名称是快照，客户端不会自己更新；要刷新用量就重新 export 并分发
 
# 服务器：重新渲染并打包，用量与异常标记随之更新
sudo bash bin/deploy/device.sh export laptop

配置告警

monitor.sh 在每次探针之后评估阈值，命中即推送。先验证凭据，再交给定时器：

sudo bash bin/deploy/ops/monitor.sh --alert-test     # 发一条测试消息，验证通道
sudo bash bin/deploy/ops/monitor.sh --alert-check    # 只评估阈值，不跑探针
sudo bash bin/deploy/ops/monitor.sh                  # 装定时器，每 5 分钟跑一次

一个通道都没配时，异常只写进 probe.log，不影响探针本身。通道取值见参数说明。

检查与验证

  • 客户端导入配置后，节点名应形如 vps · 3.6G/1T，用量与实际 vnstat -m 一致
  • --alert-test 能在手机或邮箱收到消息
  • 异常时名称后出现 ⚠，且 monitor.sh --status 里能看到对应探针记录

下一步

日常维护与备份见第 6 页；节点异常处置见排查手册。

变量默认含义

推送通道可同时配置多个，任一成功即算送达。下列通道在大陆可直连：

通道变量费用与限制

告警量小，配一个通道即可；怕单通道故障时再补一个。

要调整异常标记的时间窗口，在服务器渲染前给变量：PROBE_MAX_AGE_MIN=30 sudo -E bash bin/deploy/device.sh export laptop。

常见错误与排查

现象原因处理
告警一直没到手机通道未配置，或凭据错误monitor.sh --alert-test 发测试消息；企业微信机器人有频率上限，连续测试会静默失败
节点名里的用量不更新名称是渲染时的快照重新 device.sh export 并让客户端重新导入
探针停摆后仍报异常旧记录超龄仍参与判断异常标记与告警只认 PROBE_MAX_AGE_MIN 分钟内的记录，超龄视为无数据；确认定时器在跑
名称过长被客户端截断用量与符号叠加后超出显示宽度用 NODE_LABEL 缩短前缀，或调低 MONTHLY_QUOTA 之外的显示精度

为什么不改用标准订阅服务

商用机场的订阅链接除返回配置正文外，还带几个响应头，客户端读头即可显示用量与到期。核心是 subscription-userinfo：

subscription-userinfo: upload=1234; download=2234; total=1099511627776; expire=1798761600
content-disposition: attachment; filename="vps.yaml"
profile-update-interval: 24
profile-web-page-url: https://example.com

要显示实时用量与到期，需要一个独立的 HTTP 服务：读取 vnstat 与配额，生成配置正文并附上响应头。代价是三处新增：一个常驻服务与一个对外端口（当前 443/tcp 被 REALITY 占用，订阅只能另开端口并靠 token 保护）；一套 token 分发与轮换机制，等价于再维护一份凭据；Clash 系需要 YAML，而现有模板是 sing-box JSON，要另写一份模板。

设备数量少、只有一两个人使用时，节点名方案覆盖了同样的信息，不值得为此增加一个公开服务。另外两类已知限制：多数实现只对含 clash 的 UA 返回该响应头；sing-box 官方以「不在客户端解析代理分享格式」为由不支持订阅头，因此 sing-box 系客户端即便接了订阅也不会显示用量。
