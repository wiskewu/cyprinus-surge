部署步骤

一台 KVM VPS + sing-box，6 步（第 4 步可选）。除第 5 步外，命令都在服务器上执行。

懒人路径：不想逐步执行？一键脚本 deploy.sh 会扫描每一步的状态并让你选「复用 / 覆盖 / 跳过」，也支持一键卸载重装。它的步骤名与本表不同，对照见 一键脚本页。
#做什么命令产物
1系统初始化（含 SSH 加固）bash bin/deploy/one/system.sh加固好的系统
2装 sing-box + 生成密钥bash bin/deploy/one/install-singbox.sh
bash bin/deploy/one/secrets.sh		deploy.env / client.env / devices.list
3服务端配置 + 自检bash bin/deploy/one/server.sh
bash bin/deploy/check/server.sh		可连的节点
4Hysteria2 第二入口 可选bash bin/deploy/one/hy2.sh证书，ENABLE_HY2=1
5客户端配置（在客户端机器）bash bin/deploy/client/render.shdata/sing-box-client.json
6验收 + 备份bash bin/deploy/client/verify.sh
bash bin/deploy/ops/backup.sh		验收记录
第 4 步不做也能跑。REALITY 单入口已经够用，它只是多一条抗 UDP 干扰的路。跳过它就跳到第 5 步。

第 2 步会同时建好设备名单 devices.list。多台设备请用 bin/deploy/device.sh（服务端 sudo bash bin/deploy/device.sh add laptop），不要让多台共用同一份配置，那样没法单独吊销一台。见 第 3 页。

开始前确认

  • KVM 虚拟化：systemd-detect-virt 输出 kvm（LXC / OpenVZ 开不了 TUN）
  • 系统：Debian 12 / 13 或 Ubuntu 22.04 / 24.04
  • 已经能用密钥 ssh 进来（机器刚创建时厂商注入公钥；旧机器先 ssh-copy-id）

SSH 端口全程开着

本手册的 6 步都不会关闭公网 SSH 端口，只做两件事：放行它（第 1 步自动探测真实端口，不假设是 22），以及关掉密码登录。端口什么时候关、要不要关，见 SSH 加固手册，那是可选的第 7 步，不做也完全能用。

把脚本传上去

scp -r bin root@你的服务器IP:/root/
