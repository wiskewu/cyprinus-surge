节点部署手册

一台 KVM VPS 加 sing-box，六步完成部署，第四步可选。除客户端相关步骤外，命令都在服务器上执行。

目标

交付一台可用的节点：REALITY 主入口在监听，按需追加 Hysteria2 第二入口；客户端拿到的是按设备渲染的独立配置；全程可用脚本重复执行，也可一键卸载。

准备工作

  • KVM 虚拟化：systemd-detect-virt 输出 kvm，LXC 与 OpenVZ 开不了 TUN
  • 系统：Debian 12 / 13 或 Ubuntu 22.04 / 24.04
  • 已经能用密钥登录（机器刚创建时厂商注入公钥；旧机器先 ssh-copy-id）
  • 云控制台的 VNC 或串口可用，作为失联兜底
  • 把脚本传上去：scp -r bin root@你的服务器IP:/root/

本手册的六个步骤都不会关闭公网 SSH 端口，只做两件事：放行真实端口（第 1 步自动探测，不假设是 22），关掉密码登录。要彻底关闭端口见 SSH 加固手册，那是可选的第七步，不做也完全可用。

实施步骤

#做什么命令产物
1系统初始化，含 SSH 加固bash bin/deploy/one/system.sh加固好的系统
2安装 sing-box 并生成密钥bash bin/deploy/one/install-singbox.sh
bash bin/deploy/one/secrets.sh		deploy.env / client.env / devices.list
3服务端配置、自检与降权bash bin/deploy/one/server.sh
bash bin/deploy/check/server.sh
bash bin/deploy/one/harden.sh		可连的节点，沙箱内运行
4Hysteria2 第二入口 可选bash bin/deploy/one/hy2.sh证书，ENABLE_HY2=1
5导出该设备的配置bash bin/deploy/device.sh export laptop带校验和的 tar.gz
6验收、备份与观测bash bin/deploy/client/verify.sh
bash bin/deploy/ops/backup.sh		验收记录与加密备份
第 4 步不做也能跑。REALITY 单入口已经够用，它只是多一条抗 UDP 干扰的路，跳过直接进入第 5 步。

第 2 步会同时建好设备名单 devices.list。多台设备一律用 bin/deploy/device.sh 逐台建凭据，不要让多台共用同一份配置，那样无法单独吊销。见 第 3 页。

检查与验证

每一步自带检查命令，全部通过再进入下一步。整体验收看三处：服务端自检十项全绿、加固检查三行达标、客户端验收七项全过。具体判据分别在第 3 页与第 6 页。

下一步

不想逐步执行时，用一键脚本：它扫描每步状态，让你选「复用 / 覆盖 / 跳过」，也支持一键卸载重装。步骤名与本表不同，对照见一键脚本页的映射表。

遇到问题先看排查手册：症状、日志含义、字段说明都在那里，不占用主流程。

回退与卸载

sudo bash bin/deploy/deploy.sh --uninstall --purge --yes   # 停服务、删二进制、单元与 /etc/sing-box
sudo bash bin/harden/harden.sh --uninstall                 # 撤销 SSH 加固，恢复密码登录
