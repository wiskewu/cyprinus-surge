客户端配置

主读者：在 macOS、Linux 或 Windows 上准备免密登录的运维者。本页只做一件事：让 ssh <别名> 一条命令进服务器。

一条命令完成

bash ssh-client.sh --host 203.0.113.10 --port 4061 --install-server

脚本做四件事，每件都幂等：

动作细节
生成或复用密钥已有 ~/.ssh/id_ed25519 就用它，没有则生成 Ed25519，不设口令
安装公钥先查服务器上是否已存在同一把公钥，避免重复追加；只追加，不改动其他行
写 ~/.ssh/config已有同名 Host 时保持原样
验证用 BatchMode=yes 连一次，失败即以非零退出

生成的配置

Host vps
  HostName 203.0.113.10
  Port 4061
  User root
  IdentityFile ~/.ssh/id_ed25519
  IdentitiesOnly yes

IdentitiesOnly yes 让客户端只尝试这一把密钥。服务器 MaxAuthTries 3 时，客户端若挨个试代理里的密钥，几次就会耗尽配额。

分平台说明

平台OpenSSH 来源注意
macOS系统自带钥匙串可用 ssh-add --apple-use-keychain，但本方案不需要保管口令
Linux发行版自带无额外依赖
Windows 10/11系统自带 OpenSSH Client路径为 %USERPROFILE%\.ssh；脚本在 Git Bash 或 WSL 中执行

不安装任何第三方客户端，也不使用图形工具。图形化 SSH 客户端如 WinSCP 读取同一份 ~/.ssh/config 与同一把密钥即可。

密钥的几个决定

  • 算法用 Ed25519。密钥短、签名快、无参数需要挑选。
  • 不设口令。免密登录的前提是密钥无口令；密钥文件权限设为 600。需要额外保护时用系统登录密码与全盘加密，而不是给密钥加口令后再依赖 ssh-agent。
  • 一台设备一把密钥。吊销时删掉服务器上对应那一行，不影响其他设备。

手工做法

ssh-keygen -t ed25519 -C "laptop"
ssh-copy-id -p 4061 root@203.0.113.10      # Windows 无 ssh-copy-id，用下面的写法
type %USERPROFILE%\.ssh\id_ed25519.pub | ssh -p 4061 root@203.0.113.10 "cat >> ~/.ssh/authorized_keys"
ssh -o BatchMode=yes -p 4061 root@203.0.113.10 true   # 这一步成功再继续
不要在密钥登录验证通过之前关闭密码登录。顺序颠倒会同时失去两种登录方式，此时只能走云控制台。

检查本机状态

bash ssh-client.sh --check
