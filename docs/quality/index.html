SSH 加固手册

把管理入口收敛为公钥认证的 SSH：密码登录关闭，root 只接受密钥，端口上加速率限制，失败尝试由 fail2ban 封禁。客户端使用系统自带 OpenSSH，不安装第三方组件，不分发证书。

目标

做完后应达到：仅用密钥即可登录，密码登录被服务端拒绝，速率限制与封禁规则生效，且能独立验收这三件事。四步走完即可，任何一步都可回滚。

#在哪台机器做什么命令
1客户端生成或复用 Ed25519 密钥bash bin/harden/client.sh --host <地址> --port <端口> --install-server
2客户端验证密钥能登录ssh -o BatchMode=yes <别名> true
3服务器关密码登录，加速率限制与封禁sudo bash bin/harden/harden.sh
4客户端独立验收bash bin/harden/audit.sh --alias <别名>
第 3 步之前必须完成第 2 步。脚本会检查当前会话是否经公钥认证，读不到证据就拒绝执行。顺序颠倒会让「密钥不可用」与「密码已关闭」同时成立。

准备工作

  • 云控制台的 VNC 或串口可用，作为最终兜底
  • 当前 SSH 会话保持打开，另开一个终端用于验证
  • 明确服务器地址与端口，后续命令都要用

实施步骤

按上表顺序执行，细则分别见客户端配置与服务端加固。前者覆盖密钥生成、公钥安装、~/.ssh/config 写法与免密验证；后者覆盖脚本参数、公钥清点与去重、生效值核对。

检查与验证

用验收与排障页的独立验收脚本确认结果：它在客户端运行、只读、全部检查合并为一次远程连接。失败项的含义与自救顺序也在同一页。

下一步

需要调整默认值或评估额外加固项时看参数与取舍：脚本参数默认值、ufw limit 行为、fail2ban 规则，以及可选的双因子方案与本手册明确放弃的加固项。

回退与卸载

sudo bash bin/harden/harden.sh --uninstall

该命令删除加固片段，从备份还原被就地改写的文件，恢复密码登录与普通放行规则，然后 reload sshd。回滚后应立刻用密码登录验证一次，再关闭当前会话；处理完问题后重新执行加固。

命令手册

动作命令
配置客户端密钥与别名bash bin/harden/client.sh --host 地址 --port 端口 --alias 名字 --install-server
应用服务端加固sudo bash bin/harden/harden.sh
查看现状sudo bash bin/harden/harden.sh --check
独立验收bash bin/harden/audit.sh --alias 名字
回滚sudo bash bin/harden/harden.sh --uninstall

参数说明

三支脚本的主要参数与默认值：harden.sh 的 --check、--keys、--dedupe、--uninstall、--whitelist、--force；client.sh 的 --host、--port、--user、--alias、--install-server、--prune；audit.sh 的 --alias 或 --host。逐项默认值与副作用见参数与取舍。

常见错误与排查

现象原因处理
第 3 步拒绝执行当前会话不是公钥认证，脚本无法确认密钥可用先用 ssh -o BatchMode=yes 别名 true 验证，通过后再执行
验收第 3 项仍提示密码排序更靠前的配置写了 PasswordAuthentication yes改靠前那一行后 systemctl reload ssh，见验收与排障
与服务器完全失联密码已关闭且密钥不可用走云控制台 VNC，执行 sudo bash bin/harden/harden.sh --uninstall

为什么不用 SPA

单包授权（SPA）能把端口从扫描结果里藏起来，代价是每台客户端都要跑一个专用程序。实测两条都走不通：

路线实测结论
fwknopWindows 没有官方构建，收口后那台机器无法登录；服务端 62201/udp 长期对外
WireGuard 管理内网服务端在受控环境下可用，但当前宽带对目标地址的 UDP 全端口丢弃，握手都发不出去；换端口、停代理软件均无效

两条路线的共同前提是「客户端能主动发包到服务器的某个非 TCP 端口」。这个前提不成立时，再精巧的授权协议也无法落地。相比之下 SSH 走 TCP，而 TCP 在该环境下正常。代价是端口对扫描器可见，用三层补偿：仅公钥、速率限制、失败封禁。

换来的另两项收益：不分发证书与密钥文件，客户端只做一次 ssh-keygen 与一次公钥安装；不引入守护进程与内核模块，1 GB 内存的机器上不增加常驻负担。
