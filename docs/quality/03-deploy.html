4 · 部署

三个脚本，彼此独立，可以分别在不同机器上跑。全部幂等：改完配置重跑即可，不会留下半成品。

把脚本传上去

scp -r docs/quality/scripts root@<服务器>:/root/ssh-spa     # 或者只 scp 你要用的那一个

第 1 步 · 生成密钥

在你自己安全的机器上跑，不要在服务器上生成：

bash 00-gen-keys.sh --hosts "server1=203.0.113.10 server2=198.51.100.7" --clients "laptop phone"

产出 spa-keys.env（服务端，含全部设备）+ clients/{laptop,phone}.env。详见 第 2 页。

第 2 步 · 服务端

scp spa-keys.env root@<服务器>:/root/
ssh root@<服务器> 'bash /root/ssh-spa/10-server.sh --keys /root/spa-keys.env'

按顺序做了五件事：

  1. 装 fwknop-server（Debian 包名，客户端才是 fwknop-client）
  2. 渲染 /etc/fwknop/fwknopd.conf：按默认路由网卡写 PCAP_INTF，嗅探端口取 SPA_PORT，跳转规则放在 INPUT 第 1 位，防重放三项全开。包自带版本备份为 fwknopd.conf.orig
  3. 渲染 /etc/fwknop/access.conf（0600）：从密钥包逐个 stanza 展开，并自检 stanza 数 == 密钥组数
  4. 启动 fwknop-server：起不来就打日志退出，此时防火墙还没动；起来了还要确认 FWKNOP_INPUT 跳转真的插上了
  5. 防火墙：ufw allow 62201/udp，22 保持原样；改完 ufw 后自动重启一次 fwknopd（见 第 5 页）
渲染出来的 fwknopd.conf
PCAP_INTF                eth0;
PCAP_FILTER              udp port 62201;

FLUSH_IPT_AT_INIT        Y;
FLUSH_IPT_AT_EXIT        Y;
ENABLE_IPT_COMMENT_CHECK Y;

# 防重放：时间戳 + 摘要缓存（进程重启后仍认得旧包）
ENABLE_SPA_PACKET_AGING  Y;
MAX_SPA_PACKET_AGE       120;
ENABLE_DIGEST_PERSISTENCE Y;

# 跳转规则插在 INPUT 第 1 位，因此在 ufw 的链之前求值
IPT_INPUT_ACCESS         ACCEPT, filter, INPUT, 1, FWKNOP_INPUT, 1;
ENABLE_IPT_FORWARDING    N;
ENABLE_IPT_SNAT          N;
ENABLE_IPT_OUTPUT        N;
ENABLE_IPT_LOCAL_NAT     N;

SYSLOG_ID                fwknopd;

第 3 步 · 客户端

每台机器各跑一次，只给它自己那一份密钥：

scp clients/laptop.env <你的机器>:~/
ssh <你的机器> 'bash 20-client.sh --keys ~/laptop.env'

做了三件事：装 fwknop；写 ~/.fwknoprc（0600）；往 ~/.ssh/config 追加一个托管块。

托管块是幂等的。带 # BEGIN ssh-spa … # END ssh-spa 标记，重跑只原地替换并清掉多余空行，不会越堆越多；--uninstall 摘掉之后与原文件逐字节一致。
参数作用
--keys FILE必填。自己那一份密钥包
--name NAME覆盖包里的 CLIENT_NAME
--no-ssh只写 ~/.fwknoprc，不碰 ~/.ssh/config
--status显示当前配置
--uninstall还原 ~/.fwknoprc，删掉托管块

装包路径按顺序探测：brew → apt（fwknop-client）→ pacman。缺 nc 只警告不中止，因为 ProxyCommand 的最后一步要它（Debian/Ubuntu：apt install netcat-openbsd）。

第 4 步 · 收口

顺序不能反。先在当前这个 SSH 会话里另开一个连接，确认能进得来，再收口。
bash /root/ssh-spa/10-server.sh --keys /root/spa-keys.env --close-ssh

它会删除公网 22/tcp 规则（ufw limit 和 ufw allow 两种都试），然后重启 fwknopd 恢复跳转规则。

锁门急救

万一还是锁了——云厂商控制台的 VNC / 串口，或者你之前装了 Tailscale（见 第 5 页）：

sudo systemctl stop fwknop-server
sudo iptables -D INPUT -j FWKNOP_INPUT
sudo ufw allow 22/tcp

或者直接让脚本还原（保留密钥包）：

sudo bash 10-server.sh --uninstall     # 还原 fwknopd.conf，恢复公网 SSH 规则
sudo bash 10-server.sh --purge         # 上面这些，再删掉 access.conf 与密钥包

服务端参数

参数作用
--keys FILE密钥包路径，默认 ./spa-keys.env
--close-ssh删掉公网 SSH 规则。确认客户端能进门之后再加
--status只看状态，不改任何东西
--uninstall停服务、还原 fwknopd.conf、恢复公网 SSH 规则
--purge上面这些，再删掉 access.conf 和密钥包

共用函数

三个脚本共用 lib.sh（log/warn/die、need_root、load_env、spa_keys_for、valid_name、host_count、gen_key）。改密钥包格式只需要动 spa_keys_for 一个函数。
