4 · Hysteria2 第二入口（可选）

REALITY 单入口已经可用，本页是可选加固：用 Hysteria2 增加一条抗 UDP 干扰的路径。需要有一个域名，DNS 托管在 Cloudflare。

目标

完成 ACME 证书签发与 UDP 入口监听，使客户端配置里出现 proxy-hy2 出站，并能通过抓包与验收脚本证明这条链路真的承载流量。

准备工作

三样材料缺一不可，缺一样就只能中止：

  1. 入口域名：一条 A 记录指向服务器 IP，Cloudflare 代理关闭（灰云）。证书按这个域名签，客户端也连这个域名。
  2. Cloudflare API Token：权限选「编辑区域 DNS」，DNS-01 验证要用。
  3. 邮箱：证书到期通知地址，acme.sh 注册账号时使用。

用 deploy.sh 时这三样会在开局的材料清单里列出，--yes 且缺料会直接退出码 2，不会跑到发证阶段才失败。云安全组与 ufw 都要放行 8443-8447/udp。

实施步骤

cd /root
bash bin/deploy/one/hy2.sh          # 输入域名 / 邮箱 / Token，自动签发并续期
bash bin/deploy/one/server.sh       # 服务端开始监听 UDP
bash bin/deploy/check/server.sh

# 可选：让客户端端口跳跃真正可用
bash bin/deploy/one/port-hop.sh

完成后回到第 5 页重新导出该设备的配置，渲染会读到 ENABLE_HY2=1，客户端因此多出一个 proxy-hy2 出站。

检查与验证

客户端配置里多出 proxy-hy2，与 proxy 一起挂进 auto。auto 是 urltest，route.final 指向它，所以「出口是服务器 IP」说明不了任何事，很可能一直是 REALITY 在承载。要证明 hy2 可用，得单独把它拎出来跑。

服务端在监听。hysteria2 走 UDP，ss 要用 -u：

systemctl is-active sing-box
ss -ulnp | grep ':8443'
sudo bash bin/deploy/check/server.sh     # 自带「UDP 8443 在监听」一项

客户端配置的形状。

jq -r '.outbounds[] | "\(.tag)\t\(.type)"' client.json
# proxy      vless
# proxy-hy2  hysteria2
# auto       urltest
# direct     direct
jq -r '.route.final' client.json          # ENABLE_HY2=1 时应为 auto

一条命令验证。验收脚本会从手上的配置派生一份副本：所有指向其它代理出站的引用改写成 proxy-hy2，出站裁到只剩 proxy-hy2 与 direct，入站换成本地 mixed 端口，前台跑起来验收、跑完自动清理。不改原配置，也不需要 root。

HY2_ONLY=1 CONFIG=./sing-box-client-laptop-desktop.json SERVER_IP=你的服务器IP VLESS_PORT=443 \
  bash bin/deploy/client/verify.sh

CONFIG 指向服务器发来的那份 JSON，不需要 client.env。退出码沿用脚本约定：0 全过 / 1 有失败项 / 2 临时实例没起来或本地代理不可用。临时实例的日志留在系统临时目录，失败时脚本会打尾部。

抓包确认走的是哪一个。hy2 是 QUIC over UDP，REALITY 是 TCP 443：

# 客户端
sudo tcpdump -ni en0 'udp portrange 8443-8447' -c 20
sudo tcpdump -ni en0 'tcp port 443' -c 20

# 服务端对账
sudo tcpdump -ni any 'udp portrange 8443-8447' -c 10
sudo journalctl -u sing-box -n 100 --no-pager | grep -iE 'hysteria|hy2'

只有区间内的 UDP、没有到服务器的 TCP 443，才是 hy2 在承载。server_ports 生效时，抓到的目的端口会在 8443–8447 之间变化。

urltest 会不会选它。auto 每 3 分钟测一次 https://www.gstatic.com/generate_204，tolerance 为 100ms，只有候选比当前快出 100ms 才切换。REALITY 通常先测赢，hy2 长期备而不用，这是主备设计而非配置错误。要让它常驻，把 auto.outbounds 收成只剩 proxy-hy2，或把 route.final 指向 proxy-hy2。

下一步

回到第 3 页重跑服务端渲染与自检，再到第 5 页重新导出并分发客户端配置。

回退与卸载

# 只关第二入口，保留证书
sudo bash bin/deploy/deploy.sh --only server --overwrite --yes   # ENABLE_HY2=0 时重跑
sudo bash bin/deploy/deploy.sh --only porthop --uninstall --yes  # 撤销端口跳跃规则

关闭后客户端配置里的 proxy-hy2 会消失，需要重新导出分发。证书保留在 /etc/sing-box 下，重新开启无需重签。

命令手册

bash bin/deploy/one/hy2.sh                  # 签发或续期证书并安装到 /etc/sing-box
bash bin/deploy/one/server.sh               # 重新渲染，开始监听 UDP
bash bin/deploy/one/port-hop.sh             # 可选：配置端口跳跃
ss -ulnp | grep ':8443'                     # 核对 UDP 监听
HY2_ONLY=1 CONFIG=./客户端配置.json SERVER_IP=服务器IP bash bin/deploy/client/verify.sh

参数说明

项默认说明
DOMAIN空入口域名，留空则跳过整段证书流程
CF_TOKEN空Cloudflare API Token，DNS-01 验证用
ACME_EMAIL空证书到期通知地址
ENABLE_HY20为 1 时渲染 proxy-hy2 出站并监听 UDP
HY2_ONLY=1关派生配置并起临时实例跑完整验收，需要本机有 sing-box
HY2_ONLY=emit关只生成一份只走 hy2 的配置，不起进程、不联网、不需要 sing-box
CONFIG./client.json要派生的客户端配置，device.sh 生成的 *-desktop.json 直接用
HY2_TAGproxy-hy2出站 tag，改了模板或手写过配置时使用
HY2_PROBE_PORT2081临时 mixed 入站端口，与 2080 错开
SING_BOX_BINsing-box要执行的二进制，非 PATH 内时给绝对路径
HY2_OUThy2-only.jsonemit 模式的输出文件

没有本机 sing-box 时用 emit 生成一份只含 hy2 出站的配置，导入平台客户端即可，不必装第二个核心：

HY2_ONLY=emit CONFIG=./client.json HY2_OUT=./hy2-only.json \
  bash bin/deploy/client/verify.sh
生成结果说明
出站只剩 proxy-hy2 与 direct原来的 auto 与 proxy 被移除，引用改指 proxy-hy2
route.final = proxy-hy2没有代理组可选，导入后必然只走 hy2
dns.servers[].detour、http_clients[].detour、route.rules[].outbound同样改指 proxy-hy2，不留悬空 tag
入站原样保留TUN 与本地混合端口都不动，交给客户端自己的隧道管理

导入后按客户端分配的本地端口跑普通验收，所有检查都会经由 hy2：

PROXY=socks5h://127.0.0.1:<客户端端口> SERVER_IP=<服务器IP> \
  bash bin/deploy/client/verify.sh

常见错误与排查

现象原因与处理
QUIC 握手失败，日志里几乎没有有效信息两端 obfs salamander 密码不一致，对比 out-hy2.json.tmpl 与 in-hy2.json.tmpl 渲染出来的值
TLS 报 SNI 或证书错误客户端 tls.server_name 与服务端证书域名不一致
本地抓包有 UDP 出去，服务端抓不到UDP 出境被拦，校园网与公司网常见
8443 通，跳到区间内其它端口就失败外层安全组只放了 8443，补 8443-8447/udp
acme.sh 打印 Domains not changed. 或 Skipping.不是失败：该域名已有证书且未到续期时间，脚本会把已有证书装到 /etc/sing-box。要强制重签加 --force，注意同一域名的每周签发上限
HY2_ONLY=1 报临时实例没起来看脚本打出的日志尾部：多半是 CONFIG 里没有 proxy-hy2，或派生配置过不了 sing-box check
验收时本机没有 sing-box改用 HY2_ONLY=emit 生成配置导入客户端，再用客户端端口跑验收
